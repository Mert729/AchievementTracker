# Achievement Tracker 🏆

A web-based catalog and management application designed to centralize your in-game achievements and track your progress in one place.

## 🚀 Current Features
* **Achievement Tracking:** Add played games and track the progress of specific achievements.
* **Catalog Management:** View your game library through a clean, structured UI.

## 🔮 Roadmap (Upcoming Features)
* **Steam API Integration:** Automatic fetching of user libraries, games, and achievement data.
* **User Guides:** Allowing players to write and share their own solutions and tactics for specific achievements.
* **AI-Powered Solution Assistant:** Instantly generating step-by-step guides for difficult achievements using artificial intelligence.
* **User System:** Authentication structure and personalized progress bars.

## 💻 Technologies Used
* ASP.NET Core & C#
* Entity Framework Core
* SQL Server
* Bootstrap & Kendo UI
